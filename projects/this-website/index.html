This is where I talk about the things I've done and plan to do with the website

Now I know this site isn't pretty, but it's mine. I created this site to show off my projects and keep everything organized. I have lots of projects and zero documentation. I wanted to change that, and I had an idea of how.

I've been using this note-taking tool called Obsidian, which uses the Markdown file format to structure and modify text and documents. It has additional features that allow you to link notes together and view them as a live map. Each node is clickable and will take you to its respective document. Here is an example of a parts map I created that shows the list of parts I own and what device, if any, they're in.

Markdown is a very fast and useful language. It's basically just a reskin of HTML, which is what made me realize making a website doesn't need to be complicated. I was already making webpages; I just needed to turn them from Markdown to HTML, and boom, I had a site. I wanted to go with something simple, so I set some guidelines.

  • Minimal to no JS
    • I didn't want to deal with security because this was supposed to be a local nginx instance.
    • I'll figure out how to use it safely later; I want a place to put my stuff first.
  • I want to write as much of the code as possible
    • I could use a prefab, or WordPress, or a website builder, but I just don't find that fun.
    • I actually want to know what is happening.
  • Incredibly lightweight
    • I want everything to be small and snappy, which is part of the reason I wanted to write the code by hand.

I was originally going to use an nginx container with a proxy to host the server locally. After a bit of research, I discovered that GitHub Pages would suit my needs just fine. I still needed a way to test the site locally, so I created a folder named website and loaded it with a basic index.html file. I used an nginx Docker container to host the folder on localhost and was able to load the test page.

With that working, I added a homepage, about me page, and a projects page. I didn't put much on them, just a nav bar and some introductory text. In the projects folder, I have a bunch of subfolders that hold my writeups on each project along with that page's resources like pictures.

There isn't much more to say about the site. I'm studying up on how I can have an interactive comment box or contact box using Cloudflare or something similar. I just need to catch up on documenting my latest projects. I will probably update this page when I am able to add more features to the site, but as of right now, I am just serving files.
