This is where I talk about the things I've done and plan to do with the website

Now I know this site isn't pretty, but it's mine. I will figure out spelling and grammar later. I created this site to show off my projects and keep everything organized. I have lots of projects and 0 documentation, which means instead of science, I was just messing around. I wanted to change that, and I had an idea of how.

I've been using this note-taking tool called Obsidian, which uses the Markdown file format to structure and modify text and documents. It has additional features that allow you to link notes to sort and view a live map of the notes. Each node is clickable and will take you to its respective document. Here is an example of a parts map that I created that shows the list of parts I own and what device, if any, they're in.

Markdown is a very fast and useful language. It's basically just a reskin of HTML, which is what made me realize making a website doesn't need to be complicated. I wanted to go with something simple, so I set some guidelines.

  • Minimal to no JS
    • I didn't want to deal with security because this was supposed to be a local nginx instance.
  • I want to write as much of the code as possible
    • I could use AI, I could use WordPress, I could use a website builder, but I just don't find that fun.
    • I actually want to know what is happening.
  • Incredibly lightweight
    • I want everything to be small and snappy, which is part of the reason I wanted to write the code by hand.
